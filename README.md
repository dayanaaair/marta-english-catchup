# Marta's English Catch-up

Интерактивный самостоятельный курс уровня Elementary по материалу English File 5th Edition, Unit 4C–5C.

## Что входит в курс

- наречия и выражения частотности;
- `can / can't`: умения, просьбы и разрешение;
- Present Continuous;
- Present Simple и Present Continuous;
- погода и времена года;
- Practical English: покупка одежды и британские цены;
- интерактивные matching-задания, автоматическая проверка и порог прохождения 80%;
- сохранение прогресса ученицы и отдельный отчёт преподавателя.

## Технологии

- Vinext / React / TypeScript;
- Cloudflare Worker;
- D1 + Drizzle для прогресса;
- OpenAI Sites для размещения рабочей версии.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run dev
```

Для работы персональных ссылок локально нужны переменные окружения `STUDENT_TOKEN` и `TEACHER_TOKEN`. Их значения намеренно не хранятся в репозитории.

## Сборка

```bash
npm run build
```

Рабочая версия размещена отдельно; репозиторий содержит только исходный код и не включает данные ученицы или секретные значения.
